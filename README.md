# 한국어 자연스러운 글쓰기

AI가 한국어 글을 쓰거나 다듬을 때 참고하는 문체 스킬입니다. 대화 답변부터 이메일, 블로그, 보고서, 작품 설명서까지 글의 형식에 맞춰 씁니다.

친구에게 파일을 보내면서 “수정된 파일을 제공하겠습니다”라고 말하면 어색합니다. “설명서 오타 고쳤어. 수정한 파일이야”라고 하면 됩니다. 이 스킬은 이런 차이를 문장과 예시로 설명합니다.

## 작성 기준

문법이 맞아도 어디에나 붙일 수 있는 표현과 지나치게 정돈된 구조가 반복되면 AI가 쓴 글처럼 읽힙니다. 누구에게 무슨 말을 하려는지 먼저 정하고, 숫자와 상황, 이름, 예시처럼 실제 내용을 담아 씁니다.

- 답이 있으면 답부터 쓰고, “물론입니다”, “좋은 질문이에요” 같은 서두는 붙이지 않습니다.
- “혁신적인”, “효과적인” 같은 평가 대신 무엇을 어떻게 했는지 씁니다.
- “~에 대한”, “~를 통해” 같은 번역투는 동사를 살려 풀어 씁니다.
- 같은 구조와 어미를 반복하거나 항목 수를 억지로 맞추지 않습니다.
- 사용자가 알려 주지 않은 개인 경험과 일화를 지어내지 않습니다.
- 할 말이 끝나면 멈추고, 교훈이나 인사로 문단을 억지로 마무리하지 않습니다.

## 사용 방법

AI에게 `SKILL.md`를 읽도록 하고, `references/examples.md`도 함께 참고하게 합니다. 그다음 원하는 글이나 수정할 원문을 전달합니다.

스킬을 불러온 뒤에는 다음처럼 요청합니다.

```text
korean-natural-writing 스킬을 참고해서 아래 문장을 다듬어줘.
선생님께 보내는 메일이고, 합니다체로 써줘.

[원문]
```

처음부터 글을 쓸 때는 독자와 형식, 전달할 내용을 알려 줍니다.

```text
korean-natural-writing 스킬을 참고해서 팀원들에게 보낼 메시지 써줘.
6시에 회식 갈 예정이고, 참석 어려운 사람은 연락해 달라는 내용이야.
```

글의 형식이 정해져 있으면 바로 작성하며, 형식이 불분명할 때는 먼저 확인합니다. 이미 정한 말투와 분량을 다시 묻거나, 짧은 대화 답변마다 형식을 고르게 하지 않습니다.

## 형식별 문체

메시지와 메신저 글은 실제 대화에 가까운 말투로 씁니다. 조사를 적당히 생략하고 “~인데”, “~는데”로 이어서 짧게 전달합니다. 업무 메일에서는 “~예정입니다”, “~부탁드립니다” 같은 표현을 그대로 쓰되, 앞뒤에 붙는 인사치레와 추상어를 줄입니다.

보고서와 설명문은 문어체로 쓰며, 같은 방향의 내용은 “~하며”로 이어 흐름을 만듭니다. 조건은 “~할 경우”, 대비는 “~지만”처럼 관계에 맞춰 씁니다. 내용이 바뀌는 자리까지 한 문장으로 묶지는 않습니다.

일상적인 글은 일반 문단을 기본으로 합니다. 마크다운 문서나 사용자가 요청한 목록·표·코드 블록, 제출용 문서에 필요한 제목과 번호는 형식에 맞춰 씁니다.

## 예시

### 회식 안내 메시지

지나치게 다듬은 글:

> 오늘 오후 6시에 회식을 진행할 예정입니다. 참석이 어려우신 분은 개별적으로 연락해 주시면 감사하겠습니다.

바꾼 글:

> 6시에 회식 갈 예정인데 참석 어려우신 분들께서는 연락 부탁드립니다.

### 파일 전달

지나치게 격식을 차린 글:

> 요청하신 작품 설명서의 오탈자 수정을 완료하였습니다. 수정된 파일을 제공하겠습니다.

바꾼 글:

> 설명서 오타 고쳤어. 수정한 파일이야.

## 파일 구성

아래 경로는 스킬 폴더 기준입니다.

| 파일 | 내용 |
| --- | --- |
| `SKILL.md` | 문체 규칙과 형식별 작성 방법 |
| `examples.md` | 요청, 어색한 글, 바꾼 글을 비교한 예시 |

## 제출용 문서

작품 설명서와 제안서처럼 항목 구조가 필요한 문서는 제목과 번호 체계, 표를 사용합니다. 제목은 내용을 드러내는 명사형으로 쓰며, 표는 구성 요소와 비교 항목, 시험 결과처럼 항목과 값이 대응하는 자료에 사용합니다.

표 안에서는 짧은 개조식으로 문체를 맞추고, 설명이 필요한 내용은 본문에 씁니다. 코드와 표에 이미 나온 내용을 해설에서 그대로 반복하지 않으며, 같은 주장은 한 곳에서 자세히 설명합니다.
